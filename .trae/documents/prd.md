## 1. 产品概述

OpenRoboOLP（Open Source Robot Offline Programming）是一款开源工业机器人离线编程软件，旨在为机器人工程师、研究人员和制造商提供免费、可扩展且社区驱动的商业 OLP 工具替代方案。

- 主要目的：普及工业机器人编程，通过开放标准、透明算法以及社区维护的后处理器生态
- 目标用户：机器人工程师、AI 研究者、创客、教育工作者、制造业企业
- 市场价值：可替代 RoboDK、Robotmaster 和 Delmia 等商业软件

## 2. 核心功能

### 2.1 用户角色
无需用户角色区分，所有访客均可浏览和下载资源。

### 2.2 功能模块
1. **首页**：英雄区、导航、软件特性、支持的机器人品牌
2. **下载页**：OpenRoboOLP 软件下载、文档资源、快速入门指南
3. **产品页**：工业机器人、视觉传感器、夹爪等硬件产品介绍
4. **反馈页**：用户反馈表单、问题报告、功能建议
5. **联系页**：业务对接联系方式、技术支持

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 首页 | Hero 区域 | 展示品牌标语、核心价值、CTA 按钮 |
| 首页 | 特性展示 | 多品牌支持、离线编程、后处理器、运动学求解 |
| 首页 | 支持品牌 | UR、KUKA、ABB、FANUC、汇川等 |
| 下载页 | 下载区域 | OpenRoboOLP 软件、Python API、示例代码下载 |
| 下载页 | 文档区域 | 快速入门、API 文档、后处理器开发指南 |
| 产品页 | 机器人 | 高性能工业机器人产品展示 |
| 产品页 | 视觉传感器 | 工业视觉传感器产品 |
| 产品页 | 夹爪 | 工业级夹爪产品 |
| 反馈页 | 反馈表单 | 用户反馈、问题报告 |
| 联系页 | 联系方式 | 商务合作、技术支持 |

## 3. 核心流程
用户访问网站 → 了解软件功能 → 下载软件和文档 → 浏览硬件产品 → 反馈问题 → 联系业务

```mermaid
    C --> D["浏览产品"]
    D --> E["反馈问题"]
    E --> F["联系业务"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色 (#0f172a)、科技蓝 (#3b82f6)、亮青色 (#06b6d4)
- **按钮风格**：圆角矩形，带有悬停阴影和过渡动画
- **字体**：Poppins 用于标题，Inter 用于正文
- **布局风格**：卡片式布局，顶部导航栏
- **图标风格**：线性图标，来自 Lucide React

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 首页 | Hero 区域 | 深色背景、渐变文字、动画效果、CTA 按钮 |
| 首页 | 特性展示 | 三列网格、图标卡片、悬停动画 |
| 首页 | 支持品牌 | 品牌 Logo 网格展示 |
| 下载页 | 下载区域 | 下载按钮、版本信息、系统要求 |
| 下载页 | 文档区域 | 卡片网格、文档图标、链接 |
| 产品页 | 产品列表 | 产品图片、规格参数、价格信息 |
| 反馈页 | 反馈表单 | 输入框、文本域、提交按钮 |
| 联系页 | 联系方式 | 邮箱、电话、地址信息 |

### 4.3 响应式设计
- Desktop-first 设计，适配移动设备
- 使用 Tailwind 响应式断点
- 触摸优化的交互元素

### 4.4 3D 场景指导（如适用）
不适用
